# Alert copy — draft, UNREVIEWED

`db/migrations/0005_alerts_outbox.sql` (Person A's) defines `alert_templates
(template_key, locale, headline, detail, reviewed_by)`. Per `docs/REVIEW.md` G:
alert copy is a template key plus interpolated params, not a stored English
sentence, and — the reason the table exists at all — the Spanish a user actually
receives for a deadline notice must be read by a person, not generated by an LLM
at read time. See `TRACK_INTERFACE.md` item 4.

**This file is that draft, and it is exactly the artifact REVIEW G warns about if
it ships unread: an LLM-authored deadline sentence.** `reviewed_by` is
deliberately left blank below. Do not seed this into `alert_templates` until a
Spanish-fluent human has read every ES row and can put their name there. That is
not a formality — it is the entire point of the table existing instead of a
runtime Translation agent.

No `template_key` values exist anywhere yet (checked: no seed file for
`alert_templates`, only the migration). `clock_key` below comes from
`contracts/fixtures/*.json`, the contract both tracks share — not from
`engine/clocks/` filenames, which don't necessarily match. Proposed key shape:
`{clock_key}_{severity}`, for the two severities that plausibly fire an alert
(`warn`, `critical`) — `clear`/`info` are display states, not alert-worthy.

`{days}` and `{date}` are params, interpolated at send time from
`clock_evaluation_outbox` / the live evaluation — never baked into the template.

## ac21_365 (AC21 365-day threshold)

Framing checked against `citation-verification.md`'s E5 finding: AC21 §106(a) is
an eligibility condition (a labor cert or I-140 pending 365+ days before the
six-year H-1B cap) for a one-year extension, not a statutory deadline, and it has
nothing to do with I-485 portability (that's the separate §106(c), 180-day rule).
Copy below says "to qualify for an extension," never "your I-485" or "deadline."

**ac21_365_warn**
- EN: **{days} days left to file for your AC21 one-year extension** — AC21 lets
  you extend your H-1B one year at a time past the six-year cap, but only if a
  labor certification or I-140 has been pending 365 days before that cap date. On
  current filings, that window closes in {days} days.
- ES: **Te quedan {days} días para presentar tu extensión de un año bajo AC21** —
  AC21 te permite extender tu H-1B un año a la vez más allá del límite de seis
  años, pero solo si una certificación laboral o I-140 ha estado pendiente 365
  días antes de esa fecha límite. Con los expedientes actuales, esa ventana cierra
  en {days} días.

**ac21_365_critical**
- EN: **No AC21 extension filing on record, {days} days left** — Nothing is on
  file that would make you eligible for a one-year AC21 extension past your
  six-year H-1B maximum. A labor certification or I-140 must be pending 365 days
  before that date to qualify.
- ES: **No hay expediente para la extensión AC21, quedan {days} días** — No hay
  ningún expediente que te haga elegible para una extensión de un año bajo AC21
  más allá de tu máximo de seis años en H-1B. Una certificación laboral o I-140
  debe estar pendiente 365 días antes de esa fecha para calificar.
